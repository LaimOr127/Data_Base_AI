# 🌐 Развертывание на виртуальном хостинге

Руководство по развертыванию DIGroup на виртуальном хостинге (Noble тариф и аналогичные).

## ⚠️ Ограничения виртуального хостинга

Виртуальный хостинг обычно **не поддерживает**:
- ❌ Docker
- ❌ Прямой доступ к системе
- ❌ Установку системных пакетов
- ❌ Запуск долгоживущих процессов

## ✅ Что можно использовать

- ✅ PHP (для API прокси)
- ✅ Python (для скриптов)
- ✅ Node.js (для приложений)
- ✅ MySQL/PostgreSQL (базы данных)
- ✅ Cron задачи
- ✅ SSH/SFTP доступ

## 🚀 Варианты развертывания

### Вариант 1: Использование Node.js (рекомендуется)

Если хостинг поддерживает Node.js:

1. **Загрузите kernel бинарник** через SFTP:
   ```bash
   scp siyuan/kernel/SiYuan-Kernel user@host:/home/user/digroup/kernel
   ```

2. **Создайте Node.js приложение-прокси** для запуска kernel

3. **Настройте через панель управления** запуск Node.js приложения

### Вариант 2: Использование PHP как прокси

Создайте PHP скрипт, который будет проксировать запросы к внешнему серверу.

### Вариант 3: VPS вместо виртуального хостинга

**Рекомендуется:** Используйте VPS вместо виртуального хостинга для:
- Полного контроля над системой
- Возможности использовать Docker
- Установки любых приложений

## 📋 Альтернативное решение: VPS

Для полноценной работы DIGroup с мониторингом рекомендуется VPS:

### Требования VPS:
- **CPU:** 2-4 ядра
- **RAM:** 4-8 GB
- **Диск:** 50+ GB SSD
- **ОС:** Ubuntu 20.04+ / Debian 11+

### Стоимость VPS:
- Timeweb VPS: от 300-500₽/месяц
- Selectel: от 400₽/месяц
- DigitalOcean: от $6/месяц (~600₽)

## 🔄 Гибридное решение

Если нужно использовать виртуальный хостинг:

1. **DIGroup на VPS** (основное приложение)
2. **Мониторинг на виртуальном хостинге** (Grafana через Node.js)
3. **Supabase** (внешняя БД для аудита)

## 📊 Сравнение

| Функция | Виртуальный хостинг | VPS |
|---------|---------------------|-----|
| Docker | ❌ | ✅ |
| Мониторинг (Prometheus+Grafana) | ❌ | ✅ |
| Полный контроль | ❌ | ✅ |
| Установка приложений | ❌ | ✅ |
| Стоимость | 670₽/мес | 300-600₽/мес |
| Простота настройки | ✅ | ⚠️ |

## 🎯 Рекомендация

Для DIGroup с мониторингом и аудитом **рекомендуется VPS**, так как:
1. Нужен Docker для Prometheus + Grafana
2. Нужен полный контроль для настройки
3. VPS дешевле или сопоставим по цене
4. Больше возможностей для расширения

Если все же нужно использовать виртуальный хостинг - рассмотрите гибридное решение.
