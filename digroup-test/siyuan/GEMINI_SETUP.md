## Как использовать

### Автоматическая настройка

При первом запуске DIGroup:
- Gemini автоматически настроен и готов к использованию
- API ключ уже установлен
- Модель: `gemini-pro`

### Ручная настройка

1. Откройте **Настройки** → **Искусственный интеллект**
2. В поле **Провайдер API** выберите:
   - **Gemini** (по умолчанию, уже настроен)
   - **OpenAI** (если нужен GPT)
   - **Azure** (если используете Azure OpenAI)

3. Для Gemini можно настроить:
   - **API ключ**: `AIzaSyCby8forvtNvqZYBCJozW-VlI0GuUQrE4A` (уже установлен)
   - **Модель**: `gemini-pro` (по умолчанию)
   - **Таймаут**: 30 секунд
   - **Максимум токенов**: 0 (без ограничений)
   - **Температура**: 1.0
   - **Максимум контекстов**: 7

### Переключение между провайдерами

Вы можете переключаться между Gemini и GPT в любой момент:
- Выберите нужный провайдер в настройках
- Все настройки сохраняются отдельно для каждого провайдера
