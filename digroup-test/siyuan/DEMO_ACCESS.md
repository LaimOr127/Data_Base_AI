## 🔧 Полезные команды для демонстрации

### Проверка статуса:
```bash
# Проверить kernel
curl http://127.0.0.1:6806/api/system/version

# Проверить Nginx
curl http://localhost:8081/api/system/version

# Проверить процессы
ps aux | grep -E "(SiYuan-Kernel|nginx)" | grep -v grep
```

### Просмотр логов:
```bash
# Логи kernel
tail -f /tmp/digroup-kernel.log

# Логи Nginx
tail -f /opt/homebrew/var/log/nginx/digroup-access.log
```

### Остановка/запуск:
```bash
# Остановить kernel
pkill -f SiYuan-Kernel

# Запустить kernel
cd /Users/alexey_pripadchev/Documents/Work/data_base/siyuan/app/kernel
./SiYuan-Kernel --wd=.. --workspace=~/DIGroup-workspace --accessAuthCode=b226ba0f30a134fe9245792118bca202 --port=6806 --mode=dev &

# Перезапустить Nginx
brew services restart nginx
```

3. Перезапустите оба сервиса
