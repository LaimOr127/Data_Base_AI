# Начало работы с DIGroup

## Запуск системы

### Первый запуск

```bash
./install.sh    # Установка Docker и зависимостей
./start.sh      # Запуск всех сервисов
```

### Последующие запуски

```bash
./start.sh
```

Или напрямую:

```bash
docker-compose up -d
```

## Доступ к сервисам

После запуска откройте в браузере:

**DIGroup (База знаний):**
- URL: http://localhost:6806
- Код доступа: указан в файле `.env`

**Grafana (Мониторинг):**
- URL: http://localhost:3000
- Логин: admin
- Пароль: digroup2026 (указан в `.env`)

**Prometheus (Метрики):**
- URL: http://localhost:9090

## Настройка автоматизации

### Автоматические бэкапы

Настройка ежедневного бэкапа в 02:00:

```bash
./setup-backup.sh
```

Или в другое время:

```bash
./setup-backup.sh 23:00  # В 23:00 каждый день
```

### Автозапуск при загрузке (Linux)

```bash
sudo ./setup-systemd.sh
```

## Основные операции

### Управление сервисами

```bash
docker-compose ps          # Статус всех сервисов
docker-compose logs -f     # Просмотр логов
docker-compose restart     # Перезапуск
docker-compose down        # Остановка
```

### Резервное копирование

```bash
./backup.sh                # Ручной бэкап
```

Бэкапы сохраняются в `./backups/` и хранятся 30 дней.

### Просмотр логов

```bash
# Логи бэкапов
tail -f logs/backup.log

# Логи cron бэкапов
tail -f logs/backup-cron.log

# Логи Docker
docker-compose logs -f digroup
```

## Мониторинг

### Dashboard в Grafana

1. Откройте http://localhost:3000
2. Войдите (admin/digroup2026)
3. Перейдите в Dashboards → DIGroup System Monitoring

### Что отслеживается

- CPU - использование процессора
- Memory - использование памяти
- Disk - использование диска
- Status - статус контейнеров
- Health - проверки работоспособности

### Алерты

При возникновении проблем система покажет:
- Высокое использование ресурсов
- Недоступность сервисов
- Ошибки в контейнерах

## Хранение данных

Все данные хранятся локально на сервере:

**Пользовательские данные:**
- `workspace/` - документы и заметки (43M)
- `data/` - служебные данные

**Системные:**
- `backups/` - резервные копии
- `logs/` - логи системы
- Docker volumes - данные Prometheus и Grafana

**Никакие данные не отправляются в облако.**
