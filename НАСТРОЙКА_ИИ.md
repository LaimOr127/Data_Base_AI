# Настройка ИИ в DIGroup

## Текущая конфигурация

Настроена облачная модель: **nemotron-3-nano:30b-cloud** через Ollama Cloud

Преимущества:
- Работает через облако (не нагружает сервер)
- Быстрая обработка запросов
- 30 миллиардов параметров
- Не требует скачивания модели

## Использование ИИ

### Базовое использование

1. Выделите текст в документе
2. Нажмите `Ctrl+/` или правую кнопку мыши → AI
3. Выберите нужное действие:
   - Улучшить текст
   - Продолжить написание
   - Перевести
   - Исправить грамматику
   - Ответить на вопрос

### Чат с ИИ

Нажмите `Ctrl+L` для открытия чата с ИИ

### Доступные действия

- Улучшение текста
- Продолжение написания
- Перевод на другие языки
- Исправление грамматики
- Генерация контента
- Ответы на вопросы
- Создание таблиц и списков

## Варианты ИИ

### Ollama Cloud (текущая настройка)

Модель: `nemotron-3-nano:30b-cloud`

Настройки в приложении:
- Настройки → AI → Ollama
- API URL: `http://host.docker.internal:11434`
- Model: `nemotron-3-nano:30b-cloud`

### Альтернативные облачные модели

Доступны через Ollama Cloud:
- `gpt-oss:120b-cloud` - очень мощная (120B параметров)
- `nemotron-3-nano:30b-cloud` - быстрая (30B параметров)

Переключение: Настройки → AI → Ollama → Model

### Локальный Ollama

Если нужна работа офлайн:

```bash
# Установка
brew install ollama  # macOS
# или
curl -fsSL https://ollama.ai/install.sh | sh  # Linux

# Запуск
ollama serve

# Загрузка модели
ollama pull llama3.2
```

Настройки в приложении:
- API URL: `http://host.docker.internal:11434` (Docker)
- API URL: `http://localhost:11434` (без Docker)
- Model: `llama3.2`

### OpenAI API / Gemini

Для использования GPT или Gemini через OpenRouter:

1. Получите API ключ на https://openrouter.ai
2. В приложении: Настройки → AI → OpenAI Compatible
3. Настройте:
   - API URL: `https://openrouter.ai/api/v1`
   - API Key: ваш ключ
   - Model: `google/gemini-flash-1.5`

## Настройка параметров

В конфигурации можно изменить:

- **Temperature** (0-2) - креативность (0 = точный, 2 = креативный)
- **Max Tokens** - максимальная длина ответа
- **Timeout** - таймаут запроса в секундах
- **Max Contexts** - количество сообщений контекста

## Решение проблем

### Сообщение "Ollama сервер не запущен"

Это информационное сообщение при старте. Можно:
- Закрыть уведомление (кнопка X)
- Отключить: Настройки → Уведомления → Системные уведомления

### ИИ не отвечает

Проверьте:
1. Настройки AI корректны
2. Есть подключение к интернету (для облачных моделей)
3. Модель доступна: `ollama list` (для Ollama)
4. Логи: `docker-compose logs -f`

### Медленная работа

Решения:
- Используйте облачную модель (nemotron-3-nano:30b-cloud)
- Уменьшите Max Tokens
- Уменьшите Max Contexts

## Безопасность

При использовании облачных ИИ:
- Данные отправляются в облако
- Не используйте для конфиденциальной информации
- Следите за лимитами API

Для максимальной приватности:
- Используйте локальный Ollama
- Все данные останутся на сервере
