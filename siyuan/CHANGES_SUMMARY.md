# Сводка изменений: Удаление системы подписок и переименование

## ✅ Выполненные изменения

### 1. Отключена система подписок

**TypeScript (Frontend):**
- `app/src/util/needSubscribe.ts`:
  - `needSubscribe()` - всегда возвращает `false` (не требует подписки)
  - `isPaidUser()` - всегда возвращает `true` (всегда платный пользователь)

**Go (Backend):**
- `kernel/model/conf.go`:
  - `IsSubscriber()` - всегда возвращает `true`
  - `IsPaidUser()` - всегда возвращает `true`

**Синхронизация:**
- `kernel/model/sync.go`:
  - Убраны проверки подписки для всех провайдеров синхронизации
  - Синхронизация теперь работает для всех пользователей бесплатно

### 2. Убраны UI элементы подписки

**Desktop:**
- `app/src/config/account.ts` - убраны кнопки подписки, заменены на сообщение "Полный функционал доступен (Open Source)"
- `app/src/layout/topBar.ts` - скрыт элемент `toolbarVIP`

**Mobile:**
- `app/src/mobile/settings/account.ts` - убраны элементы подписки

### 3. Переименование в DIGroup

**Уже выполнено ранее:**
- Все упоминания "SiYuan" заменены на "DIGroup" в русской локализации
- `app/package.json` - название приложения
- `app/electron/main.js` - User-Agent и пути
- `app/electron/init.html` - заголовки окон

**Примечание:** Название в главном меню берется из `window.siyuan.languages.siyuanNote`, которое уже заменено на "DIGroup" в `ru_RU.json`. После пересборки frontend это будет отображаться корректно.
