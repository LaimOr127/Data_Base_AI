## 🔐 Формат учетных данных

### Логин:
- Формируется из инициалов: **Первая буква фамилии + Первая буква имени**
- Примеры:
  - "Шулаков Андрей Дмитриевич" → `sha`
  - "Фролов Константин Сергеевич" → `fk`
  - "Припадчев Алексей Анатольевич" → `pa`

### Пароль:
- Формируется из инициалов + "123": **Инициалы + "123"**
- Примеры:
  - `sha123`
  - `fk123`
  - `pa123`

### Гостевой доступ:
- **Логин:** `guest`
- **Пароль:** `guest123`
- **Роль:** Visitor (только чтение)

## 🌐 Доступ для пользователей

### Основной доступ (через AccessAuthCode):

1. Откройте `http://localhost:8081` (или IP сервера)
2. Введите общий AccessAuthCode: `b226ba0f30a134fe9245792118bca202`
3. Получите полный доступ к системе

### Доступ через Basic Auth (для API):

Для программного доступа через API можно использовать Basic Authentication:

```bash
curl -u логин:пароль http://localhost:8081/api/system/version
```

Примеры:
```bash
curl -u sha:sha123 http://localhost:8081/api/system/version
curl -u guest:guest123 http://localhost:8081/api/system/version
```

## 🔄 Работа с нескольких устройств

### Настройка синхронизации:

1. **Создайте папку для синхронизации:**
   ```bash
   mkdir -p ~/DIGroup-sync
   ```

2. **Настройте в DIGroup:**
   - Откройте **Настройки** → **Синхронизация**
   - Выберите провайдер: **"Local File System"**
   - Укажите путь: `/Users/alexey_pripadchev/DIGroup-sync`
   - Включите синхронизацию

3. **На других устройствах:**
   - Настройте ту же папку синхронизации
   - Все изменения будут автоматически синхронизироваться

### Для сетевой синхронизации:

Используйте общую сетевую папку или облачный диск:
- Сетевая папка: `//192.168.1.100/shared/DIGroup-sync`
- Dropbox: `~/Dropbox/DIGroup-sync`
- iCloud: `~/Library/Mobile Documents/com~apple~CloudDocs/DIGroup-sync`

## 🔧 Управление пользователями

### Добавление нового сотрудника:

1. Добавьте сотрудника в Excel файл
2. Запустите скрипт генерации БД:
   ```bash
   cd /Users/alexey_pripadchev/Documents/Work/data_base
   python3 siyuan/scripts/create_users_db.py
   ```
3. Настройте в DIGroup:
   ```bash
   python3 siyuan/scripts/setup_digroup_users.py
   ```
4. Перезапустите kernel

### Изменение пароля:

1. Отредактируйте `users_db/users_database.json`
2. Запустите `setup_digroup_users.py`
3. Перезапустите kernel

### Отключение пользователя:

1. Установите `"active": false` в БД
2. Или удалите из конфигурации `conf.json`

## 🔒 Безопасность

### Рекомендации:

1. **Измените пароли** - текущие пароли простые (инициалы + 123)
2. **Используйте HTTPS** - для доступа по сети настройте SSL
3. **Ограничьте доступ** - используйте firewall для ограничения доступа
4. **Регулярные бэкапы** - делайте резервные копии данных

### Для продакшена:

- Настройте сложные пароли
- Используйте систему смены паролей
- Настройте HTTPS через Nginx
- Используйте VPN для доступа

## 🐛 Решение проблем

### Проблема: Пользователь не может войти

**Решение:**
1. Проверьте логин и пароль в `users_db/users_list.txt`
2. Убедитесь, что пользователь активен в БД
3. Проверьте конфигурацию: `cat ~/DIGroup-workspace/conf/conf.json | grep -A 5 "publish"`

### Проблема: Синхронизация не работает

**Решение:**
1. Проверьте настройки синхронизации в интерфейсе
2. Убедитесь, что папка синхронизации существует и доступна
3. Проверьте логи: `tail -f /tmp/digroup-kernel.log | grep sync`

### Проблема: Доступ с другого устройства

**Решение:**
1. Убедитесь, что используется общая папка синхронизации
2. Проверьте сетевой доступ к папке
3. Настройте Nginx для доступа по IP (см. `IP_ACCESS_SETUP.md`)
