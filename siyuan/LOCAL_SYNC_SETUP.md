# Настройка локальной синхронизации для теста

## 🎯 Цель: Синхронизация через локальную файловую систему

Локальная синхронизация позволяет синхронизировать данные между несколькими установками DIGroup через общую папку на вашем компьютере или в сети.

---

## 📋 Способ 1: Через интерфейс (рекомендуется)

### Шаг 1: Откройте настройки синхронизации

1. Откройте DIGroup: `http://localhost:8081`
2. Войдите с AccessAuthCode: `b226ba0f30a134fe9245792118bca202`
3. Перейдите в **Настройки** → **Синхронизация**

### Шаг 2: Выберите провайдер

1. В разделе **Провайдер синхронизации** выберите **"Local File System"**
2. Нажмите **"Настроить"**

### Шаг 3: Укажите путь к папке синхронизации

**Для теста на вашем ноутбуке:**

Создайте папку для синхронизации:
```bash
mkdir -p ~/DIGroup-sync
```

Введите путь в настройках:
```
/Users/alexey_pripadchev/DIGroup-sync
```

**Важно:**
- Папка должна существовать
- Папка не должна быть внутри workspace
- Папка не должна быть родительской для workspace

### Шаг 4: Включите синхронизацию

1. Нажмите **"Включить облачную синхронизацию"**
2. Выберите или создайте директорию синхронизации (например, `main`)
3. Нажмите **"Создать"** или **"Выбрать"**

## 📋 Способ 2: Через конфигурационный файл

### Шаг 1: Найдите файл конфигурации

```bash
# Путь к конфигурации
~/DIGroup-workspace/conf/conf.json
```

Или если используется другой workspace:
```bash
# Проверьте путь в логах kernel
tail /tmp/digroup-kernel.log | grep workspace
```

### Шаг 2: Создайте папку для синхронизации

```bash
mkdir -p ~/DIGroup-sync
```

### Шаг 3: Отредактируйте конфигурацию

Откройте `conf.json` и найдите секцию `sync`:

```json
{
  "sync": {
    "enabled": true,
    "provider": 4,
    "cloudName": "main",
    "local": {
      "endpoint": "/Users/alexey_pripadchev/DIGroup-sync",
      "timeout": 30,
      "concurrentReqs": 8
    }
  }
}
```

**Параметры:**
- `provider: 4` - Local File System (4 = ProviderLocal)
- `enabled: true` - включить синхронизацию
- `cloudName: "main"` - имя директории синхронизации
- `local.endpoint` - путь к папке синхронизации

### Шаг 4: Перезапустите kernel

```bash
# Остановить kernel
pkill -f SiYuan-Kernel

# Запустить заново
cd /Users/alexey_pripadchev/Documents/Work/data_base/siyuan/app/kernel
./SiYuan-Kernel --wd=.. --workspace=~/DIGroup-workspace --accessAuthCode=b226ba0f30a134fe9245792118bca202 --port=6806 --mode=dev &
```

## 🌐 Синхронизация между несколькими установками

### Настройка на втором компьютере

1. Установите DIGroup на втором компьютере
2. Настройте локальную синхронизацию с той же папкой
3. Используйте общую сетевую папку или облачный диск

### Примеры путей:

**Локальная папка (для теста):**
```
/Users/alexey_pripadchev/DIGroup-sync
```

**Сетевая папка (для нескольких компьютеров):**
```
//192.168.1.100/shared/DIGroup-sync
```

**Облачный диск (Dropbox, iCloud, OneDrive):**
```
~/Dropbox/DIGroup-sync
~/Library/Mobile Documents/com~apple~CloudDocs/DIGroup-sync
```

## ✅ Проверка работы

### 1. Проверьте статус синхронизации

В интерфейсе DIGroup:
- **Настройки** → **Синхронизация**
- Должен отображаться статус: "Синхронизировано" или время последней синхронизации

### 2. Проверьте файлы в папке синхронизации

```bash
ls -la ~/DIGroup-sync/main/
```

Должны быть файлы:
- `refs/` - ссылки
- `objects/` - объекты данных
- `snapshot/` - снимки

### 3. Проверьте логи

```bash
tail -f /tmp/digroup-kernel.log | grep -i sync
```

## 🐛 Решение проблем

### Проблема 1: "endpoint is in workspace"

**Решение:** Папка синхронизации не должна быть внутри workspace или быть родительской для workspace.

Используйте отдельную папку:
```bash
mkdir -p ~/DIGroup-sync
```

### Проблема 2: "endpoint not exist"

**Решение:** Создайте папку перед настройкой:
```bash
mkdir -p ~/DIGroup-sync
```

### Проблема 3: Нет прав на запись

**Решение:** Проверьте права:
```bash
chmod -R 755 ~/DIGroup-sync
```

### Проблема 4: Синхронизация не работает

**Решение:**
1. Проверьте, что `enabled: true` в конфигурации
2. Проверьте логи: `tail -f /tmp/digroup-kernel.log`
3. Перезапустите kernel

## 📝 Быстрая настройка (скрипт)

Создайте скрипт для быстрой настройки:

```bash
#!/bin/bash
# Настройка локальной синхронизации

SYNC_DIR="$HOME/DIGroup-sync"
WORKSPACE_DIR="$HOME/DIGroup-workspace"
CONF_FILE="$WORKSPACE_DIR/conf/conf.json"

# Создать папку синхронизации
mkdir -p "$SYNC_DIR"

# Обновить конфигурацию (если файл существует)
if [ -f "$CONF_FILE" ]; then
    # Используйте jq для обновления JSON или отредактируйте вручную
    echo "Отредактируйте $CONF_FILE вручную:"
    echo "  \"sync\": {"
    echo "    \"enabled\": true,"
    echo "    \"provider\": 4,"
    echo "    \"local\": {"
    echo "      \"endpoint\": \"$SYNC_DIR\""
    echo "    }"
    echo "  }"
fi

echo "✅ Папка синхронизации создана: $SYNC_DIR"
echo "📝 Настройте синхронизацию через интерфейс или отредактируйте $CONF_FILE"
```

## 🔄 После настройки на сервере

Когда будете настраивать на сервере:

1. Создайте общую папку (например, через NFS, SMB или облачный диск)
2. Настройте локальную синхронизацию с этой папкой на всех клиентах
3. Все изменения будут синхронизироваться автоматически

---

## 💡 Советы

- Используйте отдельную папку для каждого workspace, если их несколько
- Регулярно проверяйте статус синхронизации
- При проблемах проверяйте логи kernel
- Для продакшена рассмотрите использование S3 или WebDAV вместо локальной файловой системы
