# Как работает workspace и синхронизация

## 📁 Структура workspace

Ваш workspace находится в:
```
~/DIGroup-workspace/
├── conf/          # Конфигурация
├── data/          # ⭐ ВАШИ ФАЙЛЫ И ЗАМЕТКИ ЗДЕСЬ
│   ├── assets/    # Изображения, файлы
│   ├── notebooks/ # Блокноты с заметками
│   └── ...
├── temp/          # Временные файлы
└── repo/          # Репозиторий для синхронизации (создается автоматически)
```

## 🎯 Где хранятся ваши файлы?

**Все ваши заметки и файлы хранятся в:**
```
~/DIGroup-workspace/data/
```

Это ваша основная папка с данными. Синхронизация НЕ нужна для работы с файлами - она нужна только для копирования данных между несколькими устройствами.

## 🔄 Что такое синхронизация?

Синхронизация - это механизм для **копирования** данных между несколькими установками DIGroup:

- Компьютер 1 → Общая папка → Компьютер 2
- Ноутбук → Облачный диск → Сервер

**Важно:** Синхронизация НЕ обязательна для работы! Вы можете работать с файлами без синхронизации.

## ❌ Почему нельзя выбрать папку внутри workspace?

Система не позволяет выбрать папку синхронизации:
- Внутри workspace (например, `~/DIGroup-workspace/sync/`)
- Родительскую для workspace (например, `~/DIGroup-workspace/`)

Это сделано для безопасности, чтобы избежать циклических зависимостей и потери данных.

## ✅ Правильная структура для синхронизации

### Вариант 1: Отдельная папка на том же уровне

```
~/
├── DIGroup-workspace/    # Ваш workspace (файлы здесь)
└── DIGroup-sync/         # Папка для синхронизации (отдельно!)
```

**Создайте:**
```bash
mkdir -p ~/DIGroup-sync
```

**В настройках укажите:**
```
/Users/alexey_pripadchev/DIGroup-sync
```

### Вариант 2: В домашней директории, но отдельно

```
~/
├── DIGroup-workspace/    # Workspace
├── Documents/
├── Downloads/
└── DIGroup-sync/         # Папка синхронизации
```

### Вариант 3: Облачный диск (для синхронизации между устройствами)

```
~/Dropbox/DIGroup-sync/
~/iCloud Drive/DIGroup-sync/
~/OneDrive/DIGroup-sync/
```

## 🚀 Быстрая настройка

### 1. Создайте папку для синхронизации

```bash
# Создайте папку на том же уровне, что и workspace
mkdir -p ~/DIGroup-sync
```

### 2. Настройте через интерфейс

1. Откройте DIGroup: `http://localhost:8081`
2. **Настройки** → **Синхронизация**
3. Выберите провайдер: **"Local File System"**
4. Укажите путь: `/Users/alexey_pripadchev/DIGroup-sync`
5. Включите синхронизацию

### 3. Или через конфигурацию

Отредактируйте `~/DIGroup-workspace/conf/conf.json`:

```json
{
  "sync": {
    "enabled": true,
    "provider": 4,
    "cloudName": "main",
    "local": {
      "endpoint": "/Users/alexey_pripadchev/DIGroup-sync"
    }
  }
}
```

Затем перезапустите kernel.

## 💡 Важно понимать

### Работа с файлами БЕЗ синхронизации

Вы можете работать с файлами **без синхронизации**:

1. Все ваши заметки хранятся в `~/DIGroup-workspace/data/`
2. Вы можете открывать, редактировать, создавать файлы
3. Синхронизация нужна только если у вас несколько устройств

### Когда нужна синхронизация?

- ✅ У вас несколько компьютеров/устройств
- ✅ Хотите автоматически копировать данные между ними
- ✅ Работаете в команде и нужен общий доступ

### Когда синхронизация НЕ нужна?

- ✅ Работаете только на одном компьютере
- ✅ Используете только локально
- ✅ Не нужно копировать данные между устройствами

## ❓ FAQ

### Вопрос: Могу ли я работать без синхронизации?

**Ответ:** Да! Синхронизация не обязательна. Все файлы хранятся в `~/DIGroup-workspace/data/`.

### Вопрос: Зачем тогда нужна синхронизация?

**Ответ:** Только для копирования данных между несколькими устройствами. Если у вас один компьютер - синхронизация не нужна.

### Вопрос: Можно ли использовать папку внутри workspace?

**Ответ:** Нет, система не позволит. Используйте отдельную папку на том же уровне или выше.

### Вопрос: Где хранятся мои заметки?

**Ответ:** В `~/DIGroup-workspace/data/notebooks/`. Это ваша основная папка с данными.

### Вопрос: Можно ли изменить расположение workspace?

**Ответ:** Да, но это сложнее. Лучше использовать текущий workspace и настроить синхронизацию в отдельную папку.
